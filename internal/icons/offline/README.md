# Offline icon pack

These SVGs let the shipped integrations and common starter specs render without network access.

- `sh-*` files come from Homarr Labs Dashboard Icons commit `c1f7e6b91c9e23317ac72b81f0ee3f9a4ac14aec` (Apache-2.0).
- `mdi-home.svg` comes from `@mdi/svg` 7.4.47 (Apache-2.0).
- `si-github.svg` comes from Simple Icons 16.29.0 (CC0-1.0; trademarks remain with their owners).

The Apache-2.0 text is checked in at [`schemas/LICENSE`](../../../schemas/LICENSE). Files are
embedded without modification and are served only through Veduta's icon endpoint.
